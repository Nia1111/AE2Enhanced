# AE2Enhanced Guide

**AE2Enhanced** is a Forge mod for Minecraft 1.12.2 that extends AE2 Unofficial Extended Life (AE2-UEL) with advanced automation, storage, and crafting systems.

## How to Use

- Hover over an item that has a guide page and **hold [G]** to jump straight to its page.
- Browse topics in the **navigation tree** on the left. Categories can be expanded and collapsed.
- Click blue links to jump between pages.
- Use the **theme button** in the top bar to switch color themes.
