# Network Devices

Single-block devices that extend what an ME network can do.

## Devices

- [Central ME Interface](devices/central-interface.md) — Interface that runs recipes on remote machines, with virtual batch crafting.
- [Wireless Channel](devices/wireless-channel.md) — Share grid channels wirelessly via the transmitter and receiver cards.
- [Network Access Node](devices/network-access-node.md) — Bridge RF, Mana and Starlight between blocks and the network.
- [Chunk Nodes](devices/chunk-nodes.md) — Power or Mana supply for every machine in a chunk area.
- [Collector and Recycler](devices/collector-recycler.md) — Intercept drops into the network; recycle machine outputs remotely.
- [Smart Pattern](devices/smart-pattern.md) — Multi-recipe patterns encoded by the Smart Pattern Interface.
