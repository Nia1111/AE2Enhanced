# ME Placement Tool

The <ItemLink id="me_placement_tool" /> **ME Placement Tool** places blocks directly from ME network storage. Bind it to your network in an ME security terminal first.

## Modes

- **Single**: place one block at a time.
- **Batch**: place along a direction lock: none, horizontal, vertical, north-south, or east-west (building-gadget style).
- **Cable**: places ME cables with a selectable color.

## Operations

- **G**: open the radial menu to pick a preset.
- **Middle-click** a block: set it as the current placement preset.
- Placed blocks are consumed from network storage, and placement can be undone.
