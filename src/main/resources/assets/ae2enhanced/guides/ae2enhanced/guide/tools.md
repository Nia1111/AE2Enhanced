# Tools and Terminals

Handheld devices and the cards that upgrade them.

## Tools

- [Omni Terminal](tools/omni-terminal.md) — 18-column wireless terminal with crafting, pattern encoding and upgrade cards.
- [ME Omni Tool](tools/omni-tool.md) — Multi-mode network tool: mining, placement, rotation and travel.
- [Universal Memory Card](tools/memory-card.md) — Copy, paste and batch-select machine configurations.
- [ME Placement Tool](tools/placement-tool.md) — Place blocks directly from ME network storage.
